# HCI Project Handoff

## Project Title
Professional Link-in-Bio Page

## Project Overview
This project is a simple, responsive link-in-bio website. It gives visitors one place to view a short profile and access important links, such as a portfolio, GitHub account, social profile, and contact information.

## User Problem
People often share several different links across their online profiles. Visitors may have difficulty finding the correct portfolio, social account, or contact page. This project addresses that problem by organizing important links in one clear and accessible page.

## Target Audience
- Students who want to present their academic work and online profiles.
- Recruiters, instructors, classmates, and other visitors who need quick access to a person's links.
- Individuals who want a simple personal page that works on desktop and mobile devices.

## Chosen Aesthetic Theme
**Minimalist, modern, and nature-inspired.** The interface uses a soft off-white background, deep green as the primary color, and a muted gold accent. It uses clear typography, generous spacing, rounded link cards, and a centered profile layout.

## UX and Interface Goals
1. Make the profile name and purpose easy to understand.
2. Keep the main links visible and easy to select.
3. Use consistent colors, typography, spacing, and components.
4. Support both desktop and mobile screen sizes.
5. Use semantic HTML and visible keyboard-focus states to improve accessibility.
6. Keep the page simple so visitors can find information quickly.

## Design Tokens
The global design variables are declared in the `:root` selector in `css/style.css`. They cover the color palette, typography, spacing, content width, border radius, and card shadow.
