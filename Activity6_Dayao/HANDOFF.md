## 1. Project Overview


DartPro is a website concept focused on showcasing darts equipment and accessories. The website aims to provide visitors with an organized and simple way to explore different darts products, including professional darts, flights, shafts, and accessories.


The design is inspired by modern sports equipment online stores.


## 2. Project Topic


**Website Name:** DartPro


**Website Category:** Sports Equipment / Darts Store


**Main Inspiration:** Winmau darts equipment collection from SRiPHILS.


**Website Purpose:** To showcase darts equipment and provide an easy browsing experience for darts enthusiasts.


## 3. Target Audience


The target audience includes:


Beginners who are interested in learning about darts.
Professional and experienced darts players.
People looking for darts equipment and accessories.
Darts enthusiasts who want to explore different products.
## 4. Design Theme and Color Palette


The website will use a modern, sporty, and professional design.


**Main Colors:**
Dark Charcoal (#0B0F14)
Orange (#F47718)
White (#FFFFFF)
Light Gray (#F5F5F5)
Black (#15191F)
The dark background and orange accents represent energy, focus, and competition.


## 5. Website Structure


The website consists of the following main sections:


### Home
Introduces DartPro with a headline, short description, dartboard image, and Explore Collection button.


### Features
Highlights the main qualities of the products:
Precision Gear
Quality Products
Performance
### Products
Displays different darts equipment categories:
Professional Darts
Dart Flights
Dart Shafts
Dart Accessories
### About
Provides a short introduction to DartPro, its purpose, and its goal of helping darts players explore equipment.


### Contact
Contains the website name, contact information section, slogan, and copyright information.


## 6. Navigation and User Experience


The website will have a fixed navigation header.


The header includes:
DartPro logo on the left side.
Home navigation link.
Products navigation link.
About navigation link.
Contact navigation link.
The navigation header remains at the top of the screen while visitors browse the website.


When a visitor clicks a navigation link, the page jumps directly to the selected section without smooth scrolling animation.


The logo is also clickable and returns visitors to the Home section.


## 7. Responsive Design


The website will support different screen sizes, including:


Desktop computers
Tablets
Mobile phones
The layout will adjust depending on the screen size to maintain readability and usability.


## 8. Technologies Used


The project will use:


HTML5 for website structure.
CSS3 for styling and layout.
CSS Flexbox for alignment.
CSS Grid for product layouts.
CSS Media Queries for responsive design.

## 10. Project Goals


The main goals of DartPro are:


1. Create a clean and organized website.
2. Present darts equipment in an attractive layout.
3. Provide simple and accessible navigation.
4. Maintain a consistent color scheme and visual identity.
5. Make the website responsive on different devices.
6. Create a user-friendly browsing experience.


## 11. Expected Outcome


The expected outcome is a responsive darts equipment website with a consistent sports-inspired design, a recognizable DartPro logo, a fixed navigation header, and organized product sections.


The website will serve as a student web development project demonstrating the use of HTML and CSS.
